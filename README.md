# Lightning Speed Services — website snapshot

Static copy of https://www.lightningspeedservices.com.au/ (built with Wix), captured on 2026-07-21.

- Each page is a standalone `.html` file (`index.html` is the home page).
- Images and styles are included alongside; some scripts/fonts still load from Wix CDNs, so full interactivity (forms, chat, bookings) is not preserved.
- To browse locally, open `index.html` in a browser.
